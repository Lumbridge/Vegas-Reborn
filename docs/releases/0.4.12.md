# Vegas Reborn Companion 0.4.12

Adds earned PEC XP to the original multiplayer post-game reports.

- Co-op story and Terrorist Hunt success reports preserve mission score and show earned XP alongside it.
- Co-op failure reports retain the failure message and add earned XP beneath it.
- Competitive results show the actual award as XP EARNED.
- The display reads the saved XP change across the original award transaction. Zero awards show 0 XP; missing observations show XP unavailable.
- Existing accounts, preferences, game copies and character saves are preserved by the signed update.

Validation: client native13 builds; the native regression checks and108 Python tests pass (one skip). Live retail match/rendered-layout acceptance remains open. This update changes presentation, not reward calculation.
