Vegas Reborn Companion

Extract the entire VegasReborn folder into a writable location and run
VegasReborn.exe. Python and build tools are not required on the playing PC.
You must own and install the original PC Rainbow Six Vegas and run Steam.

Choose the installed game folder, sign in, claim your player name if prompted,
and choose Play Vegas. In-game, choose Multiplayer > Online > Login. The
companion supplies a short-lived native credential. Never enter your Discord
password in the game. Keep the companion open until the game closes so your
character can synchronize. Hosting runs your original dedicated server in a
separate companion-owned copy; it is not the backend account/matchmaking service.

Borderless mode fills the selected monitor without keeping the game always on
top. Display settings apply on the next game launch. Discord desktop activity
sharing is optional; retail Discord join invites are not available yet.

The companion checks GitHub Releases at startup. Choose Update and restart
when an update is offered. The signed manifest and every downloaded file are
verified before installation. Finish playing and stop hosting before updating.
The local game copy, characters, preferences and account session are preserved.
Previous managed files remain available under .updates/backups for recovery.

Companion downloads and source: https://github.com/Lumbridge/Vegas-Reborn
Only companion files are distributed. No original game files, profiles, account
tokens, private update signing keys or backend server are included.
Retail gameplay, multiplayer and Alt-Tab acceptance are distinct from app and
updater tests. This experimental client supports the pinned original PC build.
