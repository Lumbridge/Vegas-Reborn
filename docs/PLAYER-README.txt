Vegas Reborn Companion

Extract the entire VegasReborn folder into a writable location and run
VegasReborn.exe. The .NET runtime it needs is included; nothing else has to
be installed on the playing PC. You must own and install the original PC
Rainbow Six Vegas or Rainbow Six Vegas 2 and run Steam.

Choose the game in Games, choose its installed folder, sign in, claim your player name if prompted,
and choose Launch game. In-game, choose Multiplayer > Online > Login. The
companion supplies a short-lived native credential. Never enter your Discord
password in the game. Keep the companion open until the game closes so your
character can synchronize. Use Create Match in the game for normal hosting.
Dedicated servers for Rainbow Six Vegas run from
runtime-<version>\VegasServer.exe. Run it with help for its commands; setup is
described at https://github.com/Lumbridge/Vegas-Reborn/blob/main/docs/HOSTING.md

Rainbow Six Vegas 2 uses the same sign-in and claimed player name. Unranked
multiplayer matches can be started with one player, and match XP is awarded
in full whatever the player count or team balance.
Display mode, monitor and Skip intro movies work for both games.

The interface has Games, Account and Settings
pages. Switching pages preserves the selected window size and position.

Borderless is the default display mode and fills the selected monitor without keeping the game always on
top. Display settings apply on the next game launch. Discord desktop activity
sharing is optional. While it is on, your Discord status shows a Get Vegas
Reborn button that opens the launcher's download page. Retail Discord join
invites are not available yet.
Download Maps Pack in the Maps Pack section of the Rainbow Six Vegas page adds
Ubisoft's official Maps Pack (about 727 MB) to the companion's game copy and
lets story missions be played as Terrorist Hunt, Deathmatch, Team Deathmatch
and Attack & Defend for up to 16 players. Everyone in a match needs the pack.
Remove takes it out again.
Skip intro movies is enabled by default on each game's page to bypass the startup logo and splash
sequence and continue to the menu without its intro-length waits.
Existing saved preferences are respected. Turning it off restores the original setting
in the companion's game copy. Loading screens and gameplay movies are retained.

The companion checks GitHub Releases at startup. Choose Update and restart
when an update is offered. The signed manifest and every downloaded file are
verified before installation. Downloads can finish while you play. If games
block installation, close them normally or choose Force-close games and update.
Force-close ends running original Vegas games/servers and can lose unsaved
match progress. The companion waits for its character-save work before handing
off to a visible installation progress window.
The local game copy, characters, preferences and account session are preserved.
Previous managed files remain available under .updates/backups for recovery.

Companion downloads and source: https://github.com/Lumbridge/Vegas-Reborn
Your saved PEC character is used by default in multiplayer, including Coop
Terrorist Hunt, once it is available. Choose a preset under Options > Multiplayer
> Coop Appearance to override that default. Explicit choices are remembered for
this account. Single-player appearance is unchanged.

Only companion files are distributed. No original game files, profiles, account
tokens, private update signing keys or backend server are included.
Retail gameplay, multiplayer and Alt-Tab acceptance are distinct from app and
updater tests. This client supports the pinned original PC build of each game.
